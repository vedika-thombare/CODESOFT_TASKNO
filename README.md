# Rule-Based Chatbot in Java

## About the Project

This project is a simple rule-based chatbot developed using Java. It uses if-else statements and pattern matching to identify user inputs and provide predefined responses.

## Features

* Responds to greetings such as hello, hi, and hey.
* Answers basic questions about itself.
* Responds to help and thank-you messages.
* Supports continuous conversation using a while loop.
* Ends the conversation when the user types `bye` or `exit`.
* Provides a default response for unknown inputs.

## Technologies Used

* Java
* Scanner class
* If-else statements
* While loop
* String pattern matching

## How to Run

1. Install the Java Development Kit (JDK).

2. Download `RuleBasedChatbot.java`.

3. Open a terminal in the file's folder.

4. Compile the program using:

   `javac RuleBasedChatbot.java`

5. Run the program using:

   `java RuleBasedChatbot`
